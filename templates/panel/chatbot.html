Настройки чат-бота

Тут вы можете подключить чат-бота, который будет отвечать на различные команды в чате.

Команды сгруппированы по категориям — у каждой есть кнопка «Включить все» и раскрывающаяся справка с примерами. Ответы выдаются случайным образом из заготовленных вариантов. Если вы хотите предложить свои ответы на существующую команду, или попросить новую команду - можете обратиться к автору бота.

Справка
{% if cat.id == "interactions" %}

Как задать цель: по нику — !кусь @Ник; несколько целей сразу — !лизь @A @B @C; реплаем на чужое сообщение — целью станет автор сообщения.

Особые цели: стримера — стример; себя — вы сами; кого-нибудь/рандом — случайный активный зритель; всех/чат — перечислит всех активных зрителей (если их меньше 7).

Команда без цели подчиняется настройке «Дефолтное поведение» ниже. У команд есть кулдауны — на чат и на пользователя.

{% elif cat.id == "links" %}

Сохранить ссылку может только стример: !тг @ник или !тг https://t.me/канал — сохранит ссылку на ваш телеграм-канал. Аналогично работают !тт, !ютуб и !дискорд.

Любой чаттерс может вызвать команду без аргументов (просто !тг) и получить сохранённую ссылку. !ссылки выведет всё сохранённое сразу.

!стим показывает привязанный Steam-аккаунт (привязка — в разделе «Другие настройки»), !мемы — ссылку на ваш профиль Memealerts (заполняется автоматически при подключении интеграции).

{% elif cat.id == "random" %}

Результат закрепляется за пользователем и через время перевыбирается — повторный вызов в этом окне напомнит прежний результат.

!якто — «кто ты сегодня»: результат свой у каждого и держится сутки.

!dice — кубик d6 d8 d12 d20 d100 или монетка (!монетка). С шансом 5% кубик падает под стол — поднять его можно командой !поднять.

{% else %}

!паста <текст> — стример сохраняет свою пасту (только владелец канала); !паста без аргументов — показать сохранённую; !рандомпаста — случайная паста из общей базы.

!лурк — уйти в лурк, !анлурк — вернуться.

!трусы — розыгрыш трусов среди активных зрителей. Зритель может навсегда отказаться от участия командой !запретитьтрусы.
