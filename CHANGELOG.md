# Changelog

История значимых изменений сервиса bot.quantum0.ru. Группировка по месяцам;
фиксируются только крупные изменения (мелкие правки и фиксы — нет). Новая запись
добавляется сверху в «Не выпущено»; при выкатке на прод раздел получает дату.

Ранняя история (до ноября 2026) восстановлена по публичной странице `/kinda_roadmap`.

## [17 ноября 2026]

- Мониторинг `/stats`: метрика PostgreSQL «операции» (pg_stat_database — блочный
  I/O, строчные операции, транзакции, только по базе приложения) и группа
  «Инфраструктура» — live-счётчики SQL/Redis/HTTP/MQTT/SSE/Twitch API.
- Чат-бот: префильтр сообщений до БД — стример (SELECT + 4 JOIN) грузится только
  для сообщений, совпадающих с командой/хендлером (~2% потока), остальные
  обслуживаются без запросов в Postgres.
- Чат-бот: новые реакции на адресованные боту фразы — «дай мемов» (с вариантами
  про награду мемкоинов, если она подключена).
- Система ачивок: 14 достижений за действия на сайте и в Twitch (скрытые
  условия), панель «Достижения» на профиле с уровнями-римскими цифрами.
- Карта потоков `/flowviz`: live-метрики процесса (HTTP, SQL, Redis, MQTT, SSE,
  Twitch API), частицы между узлами со скоростями по реальным данным.
- Страница «Сервер»: метрики хоста и healthcheck подсистем (staff).

## [Ноябрь 2026]

- Панель настроек разделена на отдельные страницы-разделы; команды чат-бота
  сгруппированы по категориям со справкой.
- В разделе Memealerts — история пополнений мемкоинов через награду.
- Поисковая система (нечёткий поиск пользователей); доработана игра «Найди пару».

## [Октябрь 2026]

- Система банов: фичи chat_bot/memecoins/ai_stickers/tts/site, канальные
  и глобальные баны, команды `!бан`/`!разбан` и веб-панель.
- Telegram-интеграция открыта всем: уведомления о начале стрима, автозагрузка
  ИИ-стикеров (автозагрузка клипов — бета-тестерам).
- Принудительный перенос пользователей на Memealerts API v2.
- ИИ-стикеры переведены на gpt-image-2.5-flare и gpt-image-2.5-sunburst: качество
  выше, прозрачный фон генерируется сразу (без нейросети удаления фона), обводка
  и тень рисуются по альфа-каналу. В настройках выбор из трёх моделей; все
  пользователи старой «качественной» модели переведены на 2.5 Flare.

## [Сентябрь 2026]

- Лайки стримеров.
- Модерация референсов персонажей (аппрув перед использованием в генерации).
- Оверлеи получили возможность сами добавлять свои команды в `!cmdlist` при открытии.

## [Август 2026]

- ФЗ-152: черновики юридических документов, согласие на обработку ПД,
  cookie-баннер.
- Прототип автомодерации на запретки; команда `!почесать`.
- SEO-оптимизации сайта; оптимизация взаимодействия с Memealerts.
- Проведены эксперименты с TTS — отложено до финансовой поддержки через донаты.

## [Июль 2026]

- Переработка интеграции Memealerts (v2): OAuth-флоу, фоновое обновление токенов,
  контроль награды для начисления мемкоинов из панели управления.
- ИИ-стикеры: кэш генераций, переход на gpt-image-2, локальное удаление фона,
  Docker-кэш AI-модели; настройки вынесены в отдельную страницу.
- Статистика по боту: суммарное количество обрабатываемых сообщений/наград,
  время обработки и т.п.
- Новые команды: `!ютуб`, `!мемы`, `!ссылки`. Страница `/streamers`: фильтры
  и сортировка.
- Развитие Twitch-расширения: обновление заголовков EBS.

## [Июнь 2026]

- Хранение временных данных (кулдауны команд и пр.) переведено в Redis.
- Target-команды: алиас `себя`, переработанная логика алиаса `всех`.
- Оптимизация скорости работы; ссылка на Memealerts в профиле.

## [Май 2026]

- Вебхук для словотрона.
- Сортировка стримеров по последней активности в панели управления.
- Оптимизация запросов к Memealerts, добавлен кэш; убраны дубликаты ответов
  в общих чатах.

## [Апрель 2026]

- «Отрывание» звёздочки; фикс трусов.
