# TTS — озвучка чата (бета)

> Справочник по фиче. При изменении поведения — обнови этот файл в том же коммите.

Озвучка сообщений чата синтезированным голосом; звук играет в оверлее
`/overlay/tts` (OBS). Включается в панели `/panel/tts` (бета, доступ ограничен).

## Триггеры

1. **Награда** «TTS — озвучить сообщение» (баллы канала, `POST /api/user/setup-tts`) —
   текст берётся из ввода награды.
2. **Чат-триггеры** (`twitch/chat/handlers/tts.py`), по приоритету: команда
   `!!!<текст>` → упоминание стримера → все сообщения без реплаев → все сообщения.
   Какой триггер для какой роли срабатывает — матрица разрешений
   `permissions.roles[role][trigger]` (роли: streamer/bot/moderator/vip/subscriber/
   chatter — `utils/chat_roles.py`).

## Обработка сообщения

- Проверка подключённого TTS-оверлея (SSE-канал `tts`) — без оверлея озвучка не идёт.
- Бан-гейт по фиче `tts` (fail-open — сбой проверки не блокирует озвучку).
- Кулдауны per-user и per-channel; срабатывание per-user КД — сообщение в чат.
- Очистка текста (эмодзи/пробелы), модерация запреток (см. ниже), обрезка до
  `max_length` («и ещё много много букв»), опциональная озвучка ника автора.
- Broadcast в SSE `tts` — оверлей синтезирует и проигрывает.

## Награда (`services/eventsub_service.py:reward_tts`)

Пустой текст → fulfill («штраф»); TTS выключен или оверлей не подключён → возврат
баллов; модерация заблокировала → варн в чат + Twitch-warning, баллы **не**
возвращаются; успех → SSE + fulfill. Для всех наград действует авто-фикс галочки
«автоматически выполнять» (+TG-уведомление стримеру).

## Синтез

Внешний TTS API через серверный прокси `services/tts.py` — токен не покидает
бэкенд; оверлей дергает `POST /overlay/tts/speech`. Пресеты голосов: `neco-arc`
(дефолт) и `gavrilov` («VHS 90-х»).

## Внешний ключ

`POST /api/user/tts/{key}` — озвучить произвольный текст из сторонних интеграций
(ключ выдаётся в настройках); обязательна серверная модерация запреток.

## Модерация текста (`services/moderation.py`)

`validate()`: нормализация (lower/NFKC, без пунктуации) → de-space → транслит
лат→кир → схлопывание повторов → фонетическая нормализация (о→а, звонкие→глухие)
→ substring-поиск стоп-слов (RU/EN slur-словарь). Сейчас применяется только к TTS;
планы (TODO.md): ИИ-модерация, автобан рецидивистов.

Ключевые файлы: `services/tts.py`, `twitch/chat/handlers/tts.py`,
`services/moderation.py`, `templates/tts.html`.
