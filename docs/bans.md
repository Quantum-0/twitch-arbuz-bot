# Система банов

> Справочник по фиче. При изменении поведения — обнови этот файл в том же коммите.

Единая модерация зрителей: бан по фичам, канальный или глобальный.

## Модель (таблица `bans`)

- Фичи (`schemas/enums.py:BanFeature`): `chat_bot`, `memecoins`, `ai_stickers`,
  `tts`, `site`.
- Scope: `channel` (действует на канале стримера) / `global` (во всех чатах;
  с фичей `site` — закрывает и доступ к панели).
- Срок (до 366 дней) или перманент, причина, кто выдал. Повторный бан мержит
  флаги фич SQL-side.
- Горячие проверки через Redis-кэш `bans:u:{twitch_id}` (TTL ≤60с) — сервис
  `services/bans.py`.

## Точки проверки (гейты)

- **Каждое сообщение чата**: `ChatBot._drop_for_bans` — забаненный по `chat_bot`
  молчит в командах, но виден в списках/SSE.
- **Каждая награда**: `_is_reward_banned` — отмена redemption (возврат баллов
  зрителю) + сообщение «тебе ограничен доступ».
- **TTS**: перед озвучкой (fail-open).
- **Сайт**: `site`-бан → `UserBannedError` → редирект на `/banned` (HTML) или 403
  (API) — `routers/security_helpers.py`. Staff выдать `site`-бан нельзя.

## Интерфейсы

- **Команды чата**: `!бан <логин> [30м/2ч/3д/1нед] [причина]`, `!разбан` — право
  стримера или Twitch-модератора канала (по бейджам, `utils/chat_roles.py`);
  `twitch/chat/commands/ban.py`. Канальный бан закрывает все зрительские фичи
  на канале; забанить стримера на его own канале нельзя.
- **Веб-панель `/bans`**: стример управляет банами своего канала, стафф — всеми +
  global-баны (`routers/api/bans.py`).
- **`/banned`** — страница-заглушка для глобально забаненных (причина; без
  user_auth, иначе редирект зациклится — `routers/web/pages.py:banned_page`).

## Поиск целей

`GET /api/user/search?context=bans` — нечёткий поиск по юзерам БД и активным
чаттерам канала с исключением стаффа/ботов/самого юзера (см. `docs/social.md`).
Виджет подсказок — `static/js/user-suggest.js`.
