# Промпт для доработки telegram-integration

Требуется доработать взаимодействие с Telegram

Исходники сервиса twibot-tg находятся в ~/PycharmProjects/twibot-tg

- card-status отображает статус подключения к телеграму. сейчас оно подключается зачем-то к настройкам и горит всегда красным. я предлагаю сделать так, чтоб у нас среди checks был так же тест подключения к телеграму. он будет делать запрос /healthcheck во twibot-tg (в нём тоже нужно будет добавить этот роут). Так же проанализируй возможность проверить, есть ли у бота право писать в чат и не выкинули ли его из канала. В случае ошибки скиллчека и невозможности писать в канал - писать соответствующий варнинг под кнопкой. в ином случае - зелёное. смотри примеры других card-status
- кнопка отключения телеграм интегрции сейчас одна. нужно чтоб можно было отделять каждую из четырёх
- Выпадающее меню заменить на radiobutton, т.к. для них есть стили уже
- сейчас все настройки смешиваются. у нас в панели panel/telegram.html должно быть 3 раздела: Уведомления о начале/окончании стрима, Клипы, Стикеры.
- в каждом разделе сперва идёт "Чат: {chat_name}" или "Чат: не подключён". Выводить надо именно название чата, не его айдишник
- справа от надписи "Чат: не подключён" мы должны выводить кнопку "Добавить в канал", "Добавить в группу". Для клипов и ИИ-стикеров ещё кнопка "Присылать в личку" (в chat_id записываем айдишник пользователя)
- Если чат подключён, то справа от него только кнопка "отключить". При нажатии - бот должен выйти из чата
- Если бота кикнули из чата - телеграм-бот должен сообщить основному (этому) сервису о выходе из чата и очистить записанный айди чата в бд, чтоб вновь отображалось "Чат: не подключён"
- Ниже, под "Чат: ..." идёт кнопка "включить", а далее уже настройки, применимые конкретно к этой (из трёх) интеграций
- т.к. индикатор статуса один, если получится сделать у интеграции возможность проверить, можно проверять состоит ли бот в группе/канале и для каждого из 3 чатов отдельно выводить ошибку внутри карточки статуса
- в идеале сделать так, чтоб у пользователя была возможность редактировать шаблон текста об уведомлении стрима. должно быть поле ввода, в применёнными к нему стилями, вписывающимися в дизайн сайта, в котором будет текст сообщения об уведомлении о начале стрима с плейсхолдерами вида `{title}` `{streamer}` `{category}` `{link}`. По дефолту подставляем текущий текст, но даём стримеру возможность его отредактировать, если он хочет поменять текст сообщения отправляемого при начале стрима. Под текст боксом нужно вывести подсказки, какие плейсхолдеры поддерживаются
